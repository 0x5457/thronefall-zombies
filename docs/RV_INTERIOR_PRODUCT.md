# 房车内部产品文档 · RV-GAMEPLAY

> 版本：1.0（2026-09-19）  
> 状态：以 `DEVELOPMENT.md` 的任务表为准；数值以 `src/rules.js` 为运行时唯一来源。  
> 关联：`docs/RV_INTERIOR_PROPOSAL.md`（空间/渲染方向）、`docs/GAME_DESIGN.md`（总设计）、`docs/ROADMAP.md`（后续阶段）。

## 1. 一句话定位

**外部营地决定今晚活不活得下来，房车决定接下来几晚怎么活。**

房车不是第二个仓库、不是安全屋、不是家具模拟器，而是：
1. **长期投资**：花掉和防线争抢的木材/零件，换跨夜的收益；
2. **信息与容错**：把"看得更远、撑得更久"变成可购买的选择；
3. **情感锚点**：从外面能看见自己把车变成了家。

## 2. 核心循环（必须闭环）

```
白天采集/远征 → 进房车 → 功能槽安装（3 选 1/2/3）→ 当晚立刻可感知
      ↑                                                        ↓
  黎明补给 ← 守夜结果 ← 改装/情报/医疗在夜战中生效 ←———————————┘
```

验收铁律：**任何一件家具，如果不能在"今晚"被玩家观察到效果，就是装饰，不应放在功能槽。**

## 3. 系统设计

### 3.1 槽位与解锁

| 槽位 | 数量 | 解锁 | 说明 |
|---|---:|---|---|
| 功能槽 | 3 | 第 1 晚后 +1，第 2 晚后 +1（即第 1/2/3 天各 1/2/3 个） | 工作台 / 电台 / 医疗柜 三选，逼出构筑差异 |
| 装饰槽 | 3 | 第 1 天全开 | 纯视觉，无战斗数值 |

- 同一件家具全局唯一，不可重复安装。
- 拆除返还已投入资源的 60%，与建筑一致；不能靠反复拆装刷资源（返还只针对购买价）。
- 功能槽不足时，安装按钮禁用并显示"需要第 N 夜后解锁的槽位"。

### 3.2 家具表（首版）

| id | 名称 | 槽位 | 成本 | 效果 | 当晚可观察性 |
|---|---|---|---:|---|---|
| workbench | 便携工作台 | 功能 | ▰25 ⚙4 | ① 解锁/更换武器的前置；② 每晚为当前武器选一项改装：伤害 +1 或射程 +1，黎明重置 | 伤害/射程数值与击杀速度变化 |
| radio | 短波电台 | 功能 | ▰10 ⚙6 | ① 情报页增加"今晚时间轴"；② 夜战 HUD 显示"下一路：路线 · 敌人 · 倒计时" | 提前知道从哪里、什么时候来人 |
| medcab | 医疗柜 | 功能 | ▰15 ⚙3 | 医疗包上限 +1（最多 3）；安装时补 1；每个黎明免费补 1 | HUD 医疗包数量跨夜恢复 |
| plant | 窗台绿植 | 装饰 | ▰10 | 厨房台面多一盆松苗，窗外对应暖绿剪影 | 窗外/室内可见 |
| quilt | 拼布暖毯 | 装饰 | ▰10 | 床尾多一条拼布毯，窗内暖色更厚 | 窗外/室内可见 |
| photos | 旅途照片绳 | 装饰 | ▰15 | 北墙多一排远征照片，夜里透出暖点 | 窗外/室内可见 |

数值意图：
- 第 1 天初始 80 木 / 8 零件。工作台（4 零件）与直接建塔（35 木）互相争抢，是第一个真正的取舍。
- 想同时拿"工作台 + 步枪"就必须跑一次高风险远征（山脊中继站），把白天的风险换成夜里的火力。
- 电台不能免费替代情报页的基础信息（夜晚课题与分路明细保持公开）；它卖的是**时间轴与实时预警**，让玩家能重新布位。
- 医疗柜不提高治疗量，只提高容错上限，避免和"余火守望"专长重复。

### 3.3 武器改装（工作台）

- 每天白天可在房车内二选一：`加压弹`（当前武器伤害 +1）或 `加长枪管`（当前武器射程 +1）。
- 只影响角色武器，不影响瞭望塔；黎明进入新一天时自动清空，需要重新选择。
- 未安装工作台时不可选择、也不可解锁新武器；已解锁武器的装备不受影响。
- 改装是"选择"而非叠加：同一天不能同时获得两个加成。

### 3.4 电台信息（不与现有情报冲突）

| 信息 | 无电台 | 有电台 |
|---|---|---|
| 波次名称、课题、应对建议 | ✅ | ✅ |
| 每组敌人类型/数量/路线 | ✅ | ✅ |
| 生成时间轴（第几秒出哪一组） | ❌ | ✅ |
| 夜战 HUD"下一路 + 倒计时" | ❌ | ✅ |

### 3.5 医疗柜

- `maxMedkits = 2 + (医疗柜 ? 1 : 0)`，上限 3。
- 安装时立即 +1（不超过上限）。
- 每个黎明补给时免费 +1（不超过上限）；拆除后若持有数超过上限，回到上限。
- 不改变医疗包治疗量（仍为 60）。

## 4. 窗外反馈（RV-05）

室外房车必须能被"读懂"：

1. **基础窗光**：夜晚房车朝向营地一侧的两扇窗透出暖光；床头灯关闭时明显变暗（保留现有灯开关的意义）。
2. **模块色标**：安装功能家具后，对应窗面出现独立色标与剪影——工作台琥珀、电台青色、医疗柜绿色；装饰为绿植/暖毯/照片各一个小色块。
3. **白天**：窗面保持原样，不发光；所有变化只在夜晚出现，不破坏白天截图。
4. **性能**：全部为 Basic 材质小面片，不做后处理，不新增点光源。

## 5. 交互与 UI

- 进入房车后，底部面板显示三段：固定陈设说明（折叠为一行）、**功能槽**、**装饰槽**。
- 每个槽位卡片：名称、标签、成本、效果说明、`安装` / `已安装 · 拆除返还` 按钮；禁用时显示具体原因。
- 工作台安装后出现"今晚改装"两按钮，当前选择高亮，可切换。
- 离开房车或安装/拆除后立即刷新；面板可滚动，不遮挡房间中间区域（1280×720 与窄屏均需验证）。
- 规则：白天才能安装/拆除；夜晚室内已经不可进入，无需额外分支。

## 8. 暂不做（明确写死）

- 室内战斗、敌人进屋、房车受伤的室内表现。
- 自由 3D 漫游、自由网格家具编辑器、家具旋转/叠放。
- 家具等级树、家具专属货币、装饰加任何战斗数值。
- 通过进入房车暂停/跳过夜战；夜晚门交互继续拒绝。
- 多辆房车、可进入的其他建筑。
